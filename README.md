# India, counted — a growth tracker

A single-page dashboard of India's growth story: economy, infrastructure and tech, society,
plus a state/district choropleth. Built with Vite and vanilla JS; charts by Chart.js, map by D3.

## Run it

```bash
npm install
npm run dev       # dev server with hot reload
npm run build     # production build into dist/
npm run preview   # serve the production build locally
```

Requires Node 22 (see `.nvmrc`).

## Layout

```
index.html                 page markup (copy lives here)
src/styles.css             all styling
src/main.js                entry point: wires data to renderers, nav highlight
src/charts.js              Chart.js defaults, theme colours, ledgers, pulse, then/now table, embedded charts
src/live.js                World Bank live series + offline fallback
src/map.js                 D3 choropleth (states → districts), tooltip, ranking panel, CSV upload
src/data/                  every hand-entered figure, as JSON (see below)
public/data/india.topojson state and district boundaries, served as a static file
```

## Updating the numbers

Every hand-entered figure lives in `src/data/*.json`. Edit the JSON, save, and the dev server reloads.
Nothing numeric is typed into JS or HTML except the hero headline.

**Every figure carries `source` and `asOf`.** `npm run check:data` fails if either is missing, and
lists which map states still need verifying (see below). Run it before you commit.

| File | What it holds | How to update |
|---|---|---|
| `pulse.json` | The big headline number under the hero and its sentence | Change `value`, `text` (HTML allowed), `source`, `asOf` |
| `economy.json` | `ledger`: the four Economy tiles. `quarters`: real GDP growth bars | Tiles: edit `n` (display string), `unit`, `l` (label), `source`, `asOf`, optional `note`. Quarters: append to `labels` and `values` together |
| `infra.json` | `ledger`: four Infra tiles. `upi`: August UPI volumes. `highways`: two-bar chart. `thenNow`: the comparison table | Same pattern. `thenNow` rows are display strings (`a` = 2014, `b` = latest, `d` = change) plus `source` and `asOf` |
| `society.json` | `ledger`: four Society tiles | Same pattern |
| `worldbank.json` | Offline fallback for the four live World Bank charts | Only used when the API is unreachable. Refreshed by `scripts/refresh.js` (see below) |
| `map-pci.json` | Per-state NSDP per capita for two years, plus the all-India pair | See "Map data" below |
| `districts-pci.json` | District-level figures for the map, `{ State: { District: [a, b] } }` | Generated by `scripts/import-districts.js`; can also be uploaded as CSV from the page |

The source line under a tile is rendered as `source · asOf` and, if present, `, note`
(e.g. `World Bank · 2022–23, from 16.2% in 2011–12`).

Where a chart caption says "embedded, as of …", that text is in `index.html` next to the chart and
should be bumped by hand when the underlying JSON changes.

### Known gaps, on purpose

- **Q3 FY26 real GDP growth is `null`** in `economy.json` → `quarters.values`. This is deliberate: the
  bar is drawn grey with the tooltip "not yet entered". Replace the `null` with the figure when you have it.
- **"Operational airports" and "Metro rail in operation"** in `infra.json` → `thenNow` have `source: null`
  because the original page did not record one. `check:data` will keep flagging them until you fill them in.
- **World Bank fallbacks** have `asOf: null` until `npm run refresh` has run once.

## Map data

`src/data/map-pci.json` is self-describing:

```jsonc
{
  "id": "pci", "name": "…", "unit": "₹",
  "columns": {
    "a": { "label": "2014-15", "source": "RBI Handbook of Statistics on Indian States, Table 19", "asOf": "2014-15" },
    "b": { "label": "2023-24", "source": "MoSPI state series", "asOf": "2023-24" }
  },
  "india":  { "a": 86647, "b": 188892, "source": "…", "asOf": "…" },
  "states": { "Bihar": { "a": 28671, "b": 62201, "aStatus": "approximate" }, … }
}
```

`aStatus` says how much to trust the 2014-15 column for that state:

| `aStatus` | Meaning |
|---|---|
| `verified` | Checked against RBI Handbook of Statistics on Indian States, **Table 19 — per capita NSDP, current prices** |
| `approximate` | Typed from memory. **30 states are in this state today.** Verify before publishing |
| `none` | No comparable 2014-15 series (Ladakh, Lakshadweep, DNH & DD); `a` is `null` and the state is left grey in that view |

The footnote under the ranking panel ("typed from memory except Delhi, Haryana, Puducherry; verify before
publishing") is generated from these flags, so it disappears by itself once every state is `verified`.

### Pasting in the corrected 2014-15 column

1. `npm run check:data` prints the states still marked `approximate` with their current values.
2. Open `scripts/templates/pci-2014-15.csv` (every state name pre-filled, verified values already in place),
   paste the Table 19 figures into the `value` column, save it anywhere.
3. `npm run import:pci -- path/to/your.csv`

The importer checks each state name against the topojson (and suggests the nearest match when one is
off, e.g. "Orissa" → Odisha), writes the values, and marks those states `verified`. Blank values are skipped
so you can do it in batches. `₹` and thousands separators are stripped. Use `--column b` to import the
2023-24 column the same way, or `--status approximate` if you are pasting something you have not checked.

## Boundaries

`public/data/india.topojson` is the Census 2011 state and district file from
[udit-001/india-maps-data](https://github.com/udit-001/india-maps-data) (`topojson/india.json`),
downloaded once so the page never fetches from GitHub at runtime. To refresh it:

```bash
curl -sSL -o public/data/india.topojson https://raw.githubusercontent.com/udit-001/india-maps-data/main/topojson/india.json
```

State names in `map-*.json` must match the `st_nm` property and district names the `district` property in that file.

## Live data

Four charts pull from the World Bank Indicators API on each page load (`NY.GDP.MKTP.CD`,
`NY.GDP.PCAP.CD`, `SP.DYN.LE00.IN`, `IT.NET.USER.ZS`). The dot next to the caption turns green
when live and red when the page has fallen back to `src/data/worldbank.json`.
