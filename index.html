Compare India, three maps at a time

Choose a measure and a year for each map. Maps showing the same measure share one colour scale across every year, so a darker state in one map really is higher than a lighter one in another. Hover a state to read it in all three; click to pin it.

State-wise National Accounts from the Ministry of Statistics and Programme Implementation (MoSPI), 2011-12 base, fiscal years April to March; the latest year fills in as states publish. Boundaries: Census 2011 (udit-001/india-maps-data). Lakshadweep and DNH & DD have no state accounts and stay grey.

Live series come from the World Bank Indicators API and refresh each time the page loads. Everything else is typed into the JSON files in src/data, with a source and an as-of date next to each figure — edit those files to update the site.
